# 1. لغة XVC

[← الفهرس](README.md) · [English](../en/1-xvc-language.md)

لغة XVC هي لغة البرمجة الخاصة بنظام itelxOS. البرنامج ملف نصي ينتهي
بـ `.xvc`، وتشغّله الطرفية بالأمر `run name.xvc` (أو باسمه فقط إذا كان في
`/dex`). يترجم مفسّر XVC الملف كله أولاً قبل أن يبدأ، فأي خطأ في أي سطر
يظهر برقم سطره قبل أن يعمل أي شيء.

```
# hello.xvc
let name = "itelx"
print("Hello from " + name)
print("مرحبا من XVC")
```

## شكل البرنامج

- يعمل البرنامج من أعلى إلى أسفل، ولا توجد دالة `main`.
- كل سطر فيه جملة واحدة. لوضع جملتين في سطر واحد افصل بينهما بـ `;`.
- العلامة `#` تبدأ تعليقاً حتى آخر السطر.
- الكتل تُكتب بين `{ }`، مثل: `if x > 0 { print("yes") }`.
- التعبير الطويل يمكن أن يكمل في السطر التالي إذا كان داخل `( )` أو
  `[ ]` أو `{ }`، أو إذا انتهى سطره بعلامة عملية:

  ```
  let total = price * count +
      shipping
  let days = ["sat", "sun",
      "mon"]
  ```

  انتبه: علامة العملية في **بداية** السطر تبدأ جملة جديدة، لذلك ضعها في
  آخر السطر الذي قبله.

## القيم

<div dir="rtl">

| النوع | أمثلة | ملاحظات |
|---|---|---|
| int | `42`، `-7`، `0xff`، `1_000_000` | أعداد صحيحة 64 بت. لا توجد كسور ولا أرقام عشرية. |
| bool | `true`، `false` | صح وخطأ |
| nil | `nil` | "لا شيء": مفتاح غير موجود في map، أو `input()` عند نهاية الإدخال، أو دالة بلا `return` |
| string | `"text"`، `"سلام"` | نصوص UTF-8. الدالة `len` والفهارس تعدّ الحروف لا البايتات. النص لا يمكن تعديله. |
| list | `[1, "two", [3]]` | قائمة تكبر بـ `push` |
| map | `{"a": 1, 2: "b"}` | قاموس: المفاتيح نصوص أو أعداد أو bool |
| range | `range(10)` | سلسلة أعداد لحلقات `for` |
| function | `fn` ... | الدوال قيم أيضاً |

</div>

الدالة `type(x)` تعطي اسم النوع: `"int"` و`"string"` و`"list"`...

الرموز الخاصة داخل النصوص: `\n` سطر جديد، `\t` مسافة جدولة، `\r`، `\0`،
`\e` (escape)، `\\`، `\"`، و`\u{0627}` (حرف Unicode برقمه).

ما يُعتبر "خطأ" في `if` و`while`: `nil` و`false` و`0` والنص الفارغ `""`
والقائمة الفارغة `[]`. وكل ما عدا ذلك "صح" (حتى الـ map الفارغ).

## المتغيرات

```
let count = 0          # متغير جديد
count = count + 1      # قيمة جديدة
count += 1             # نفس الشيء، و -= تعمل أيضاً
let nothing            # قيمته nil
```

المتغير الذي تصنعه بـ `let` في المستوى الأعلى من البرنامج (خارج أي كتلة)
**عام**: كل الدوال تستطيع قراءته وتغييره. أما `let` داخل كتلة (`if` أو
`while` أو `for` أو دالة) فيعيش حتى نهاية تلك الكتلة فقط.

الأسماء من حروف وأرقام و`_`، ويمكن أن تكون عربية: `let الاسم = "أحمد"`.

الكلمات المحجوزة: `let fn if elif else while for in return break continue
true false nil and or not`.

## العمليات

من الأضعف ارتباطاً إلى الأقوى:

<div dir="rtl">

| العمليات | |
|---|---|
| `or` | أول قيمة "صح" (والباقي لا يُحسب) |
| `and` | أول قيمة "خطأ" (والباقي لا يُحسب) |
| `not` | تعطي true إذا كانت القيمة "خطأ". انتبه: `not a == b` معناها `not (a == b)` |
| `==` `!=` | لأي قيمتين؛ القيم من نوعين مختلفين ليست متساوية |
| `<` `<=` `>` `>=` | بين عددين أو بين نصين |
| `+` `-` | للأعداد؛ و`+` تجمع النصوص أيضاً (`"a" + 1` تعطي `"a1"`) والقوائم |
| `*` `/` `%` | للأعداد؛ `/` تحذف الكسر (`7 / 2` = `3`)؛ و`"ab" * 3` تعطي `"ababab"` |
| `-x` | السالب |
| `f(x)` `x[i]` | استدعاء دالة، وفهرس |

</div>

القسمة على صفر توقف البرنامج بخطأ تشغيل.

## النصوص

```
let s = "itelx-os"
len(s)                 # 8
s[0]                   # "i"   (الفهرس يعطي نصاً من حرف واحد)
s[-1]                  # "s"   (الفهرس السالب يعدّ من النهاية)
substr(s, 6, 2)        # "os"  (من الموضع 6، حرفان؛ بدون العدد: حتى النهاية)
find(s, "os")          # 6     (و -1 إذا لم يوجد)
upper(s)  lower(s)  trim("  x  ")
replace(s, "-", " ")   # "itelx os"
split("a,b,c", ",")    # ["a", "b", "c"]؛ و split(s) تقسم عند المسافات
join(["a", "b"], "+")  # "a+b"
startswith(s, "ite")   endswith(s, "os")    has(s, "x-o")
str(42)                # "42"
int("42")  int("0x1f") # 42 و 31؛ و int("4x") تعطي nil، فتحقق دائماً: if n == nil { ... }
chr(1575)  ord("ا")    # "ا" و 1575
for c in "سلام" { print(c) }   # حرفاً حرفاً
```

## القوائم (list)

```
let l = [5, 3, 9]
l[0]                   # 5
l[1] = 4               # تغيير عنصر
l[2] += 1
push(l, 7)             # إضافة في النهاية
pop(l)                 # حذف الأخير وإرجاعه
insert(l, 0, 99)       # 99 في الموضع 0
removeat(l, 1)         # حذف الموضع 1 وإرجاعه
len(l)  has(l, 9)
sort(l)                # أعداد أو نصوص
reverselist(l)
l + [1, 2]             # قائمة جديدة فيها الاثنتان
for x in l { print(x) }
```

القائمة المكتوبة في البرنامج مباشرة (`[ ... ]`) تتسع حتى 255 عنصراً،
أما `push` فتكبّر القائمة ما دامت الذاكرة تكفي.

## القواميس (map)

```
let ages = {"omar": 31, "sara": 28}
ages["mona"] = 25      # إضافة أو تغيير
ages["nobody"]         # nil: مفتاح غير موجود
has(ages, "omar")      # true
keys(ages)             # قائمة المفاتيح، بلا ترتيب معيّن
for name in ages { print(name + ": " + str(ages[name])) }
```

لعرض المفاتيح مرتبة: `let k = keys(m); sort(k)`. لا يمكن حذف مفتاح: اصنع
map جديداً بدونه.

## الشروط والحلقات

```
if n < 0 {
    print("negative")
} elif n == 0 {
    print("zero")
} else {
    print("positive")
}

while n > 0 { n -= 1 }

for i in range(5) { }          # 0 1 2 3 4
for i in range(1, 6) { }       # 1 2 3 4 5
for i in range(10, 0, -2) { }  # 10 8 6 4 2
for item in list { }
for ch in "text" { }
for key in map { }
```

الأمر `break` يخرج من الحلقة، و`continue` ينتقل إلى الدورة التالية.

## الدوال

```
fn area(w, h) {
    return w * h
}
print(area(3, 4))

fn fact(n) {
    if n <= 1 { return 1 }
    return n * fact(n - 1)        # الدالة تستطيع أن تستدعي نفسها
}
```

<div dir="rtl">

- تُكتب الدوال في المستوى الأعلى من البرنامج، لا داخل كتلة.
- البرنامج يعمل من أعلى، و`fn` تعرّف دالتها عندما يصل إليها التنفيذ:
  لذلك اكتب الدوال **فوق** الكود الذي يستدعيها. أما الدوال فيما بينها
  فتستدعي بعضها بأي ترتيب.
- يجب استدعاء الدالة بعدد القيم نفسه الذي في تعريفها بالضبط.
- الدالة ترى معاملاتها ومتغيراتها (`let`) والمتغيرات العامة فقط، ولا ترى
  متغيرات الكود الذي استدعاها: مرّرها لها كمعاملات.
- الدالة التي ليس فيها `return` تعطي `nil`.
- الاستدعاء المتداخل (التكرار الذاتي) يصل حتى عمق 256.

</div>

## الإدخال والإخراج

```
print("a", 1, true)    # القيم بينها مسافات، ثم سطر جديد
write("no new line")   # بدون سطر جديد
let name = input("your name: ")     # سطر يكتبه المستخدم (و nil عند نهاية الإدخال)
let k = key()          # مفتاح واحد بدون Enter: "a" أو "enter" أو "esc" أو "up" أو "down" أو "left" أو "right" أو "f1"...
clear()                # مسح الشاشة
print(color("green") + "done" + color("reset"))
```

الألوان: `white` و`yellow` و`red` و`green` و`cyan` و`dim` و`reset`.

ما يُكتب بعد اسم البرنامج يصل إليه في القائمة `args`: العنصر `args[0]` هو
البرنامج نفسه، ثم ما كُتب بعد اسمه.

```
# greet.xvc - run greet.xvc Sara
if len(args) > 1 { print("hello " + args[1]) } else { print("use: greet <name>") }
```

## الملفات والمجلدات

```
writefile("/dex/data/a.txt", "first\n")   # تعطي true إذا نجحت
appendfile("/dex/data/a.txt", "second\n")
let text = readfile("/dex/data/a.txt")      # و nil إذا تعذّرت القراءة
exists(path)  isdir(path)  filesize(path)
listdir("/dex")        # قائمة بالأسماء
makedir("/dex/data")   removefile(path)
```

برامجك تستطيع حفظ ملفاتها في `/dex/data` (أنشئه بـ `makedir("/dex/data")`
إذا قالت `exists` إنه غير موجود). والفلاشات تظهر في `/media/NAME`.

## البرامج والوقت والعشوائية

```
run("other.xvc", "arg")   # يشغّل برنامجاً (.xvc أو .xvr) وينتظره؛ ويعطي رقم خروجه
let p = spawn("counter.xvc")  wait(p)  kill(p)   # في الخلفية
sleep(500)                # بالملّي ثانية
time()                    # الثواني منذ 1970 (ساعة الكمبيوتر)
uptime()                  # الملّي ثانية منذ بدء itelx
pid()                     # رقم عملية هذا البرنامج
random(6) + 1             # من 1 إلى 6
exit(0)                   # إنهاء البرنامج الآن برقم خروج
```

## الأخطاء

يوجد نوعان، وكلاهما يذكر اسم الملف ورقم السطر:

```
xvc: game.xvc:12: expected ')' after the arguments          (البرنامج لم يُترجم: لم يعمل شيء)
xvc: game.xvc:30: runtime error: list index 5 out of range (البرنامج توقف عند هذا السطر)
```

تستطيع إيقاف البرنامج بنفسك برسالة: `error("message")`، أو التأكد من شرط
يجب أن يكون صحيحاً: `assert(x > 0, "x must be positive")`. البرنامج الذي
لا يُترجم ينتهي برقم خروج 2، وخطأ التشغيل برقم 1.

## كل الدوال الجاهزة

<div dir="rtl">

| الدالة | ماذا تفعل |
|---|---|
| `print(...)`، `write(...)` | الطباعة، مع سطر جديد وبدونه |
| `input([prompt])` | سطر يكتبه المستخدم؛ و`nil` عند نهاية الإدخال |
| `key()` | مفتاح واحد بدون Enter |
| `clear()`، `color(name)` | مسح الشاشة؛ وكود لون |
| `len(x)` | حروف النص، أو عناصر القائمة أو الـ map، أو طول الـ range |
| `str(x)`، `int(x)`، `type(x)` | التحويل؛ واسم النوع |
| `chr(n)`، `ord(s)` | الحرف من رقمه والعكس |
| `upper`، `lower`، `trim` | النصوص (الحروف الكبيرة والصغيرة: الإنجليزية) |
| `substr(s, from[, count])`، `find(s, t)`، `replace(s, a, b)` | النصوص |
| `split(s[, sep])`، `join(list[, sep])` | النصوص والقوائم |
| `startswith(s, t)`، `endswith(s, t)` | النصوص |
| `push`، `pop`، `insert`، `removeat`، `sort`، `reverselist` | القوائم |
| `keys(map)`، `has(x, v)` | القواميس (و has تعمل على القوائم والنصوص أيضاً) |
| `range(n)`، `range(a, b[, step])` | سلاسل الأعداد لـ `for` |
| `readfile`، `writefile`، `appendfile` | الملفات |
| `exists`، `isdir`، `filesize`، `listdir`، `makedir`، `removefile` | الملفات والمجلدات |
| `run(prog, args...)`، `spawn(...)`، `wait(pid)`، `kill(pid)` | البرامج |
| `sleep(ms)`، `time()`، `uptime()`، `pid()`، `random(n)` | الوقت والعشوائية |
| `exit([code])`، `assert(cond[, msg])`، `error(msg)` | الإنهاء والأخطاء |

</div>

## الحدود

أعداد صحيحة 64 بت فقط (لا أرقام عشرية: احفظ القروش كأعداد صحيحة، `1250`
بدل 12.50)؛ البرنامج حتى 8 ميجابايت؛ النص حتى 16 ميجابايت؛ عمق الاستدعاء
256؛ و64 معاملاً للاستدعاء الواحد؛ و256 متغيراً محلياً في الدالة؛ و255
عنصراً في القائمة أو الـ map المكتوبة في البرنامج مباشرة. التطبيقات في
[`apps/xvc`](../../apps/xvc) تُظهر كل هذا وهو يعمل: حتى إن `calc.xvc` يبني
كسوراً دقيقة من الأعداد الصحيحة.
