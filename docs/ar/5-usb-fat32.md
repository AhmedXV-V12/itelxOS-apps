# 5. نقل البرامج إلى itelx بالفلاشة

[← الفهرس](README.md) · [English](../en/5-usb-fat32.md)

نظام itelx 1.3 يقرأ ويكتب على الفلاشات (وقارئات الكروت والأقراص الخارجية)
المهيأة بنظام **FAT32** (و FAT16 و FAT12 أيضاً). **أما exFAT و NTFS فلا
يقرؤهما**: الفلاشة المهيأة بأحدهما لن تظهر. ويمكن أن يكون في الفلاشة جدول
أقسام (MBR أو GPT) أو لا يكون.

## 1. هيّئ الفلاشة بنظام FAT32

التهيئة (Format) تمسح كل ما على الفلاشة.

**على ويندوز** - للفلاشات حتى 32 جيجابايت: افتح File Explorer، اضغط على
الفلاشة بالزر الأيمن، ثم *Format...*، واختر نظام الملفات **FAT32**، واكتب
اسماً للفلاشة مثل `APPS`، وفعّل *Quick Format*، ثم *Start*. أو من الطرفية
(ضع حرف فلاشتك بدل `E:`):

```
format E: /FS:FAT32 /V:APPS /Q
```

ويندوز لا يعرض FAT32 للفلاشات الأكبر من 32 جيجابايت. استخدم فلاشة أصغر، أو
أداة تهيئ الفلاشات الكبيرة بـ FAT32، أو اصنع على الفلاشة قسماً واحداً FAT32
حجمه 32 جيجابايت أو أقل (من Disk Management).

**على لينكس** (ضع اسم فلاشتك بدل `/dev/sdX`، وتعرفه بالأمر `lsblk`):

```bash
sudo mkfs.vfat -F 32 -n APPS /dev/sdX1
```

**على ماك**: افتح Disk Utility، اختر الفلاشة، ثم *Erase*، والصيغة
**MS-DOS (FAT)**.

اسم الفلاشة يصبح اسم مجلدها داخل itelx: `/media/APPS`.

## 2. انسخ التطبيقات

انسخ **محتويات** المجلد [`usb/`](../../usb) من هذا المستودع إلى أعلى
الفلاشة (الجذر)، بحيث يكون على الفلاشة:

```
update.xvr          برنامج التثبيت (ملف XVR من نوع update)
dex/                التطبيقات: برامج .xvc وملفات تنفيذية .xvr
SHA256SUMS          مجاميع التحقق لكل الملفات
README.txt
```

(من GitHub: *Code* ثم *Download ZIP*، ثم افتح مجلد `usb` داخل الملف المضغوط.)
وبرامجك أنت ضعها في مجلد `dex/` على الفلاشة بجانبها.

أخرج الفلاشة من الكمبيوتر بأمان (Eject) قبل نزعها.

## 3. وصّلها بـ itelx

يرى itelx الفلاشة فوراً، ولأن في أعلاها ملف `update.xvr` فإنه يسأل:

```
[USB] /media/APPS holds an itelx update: itelxOS apps 1.0 (structure valid; unsigned)
are you need update ? (yes/no) yes
itelxOS apps - installing from /media/APPS
  installed /dex/2048.xvr            16008 bytes
  ...
update done: 28 program(s) installed (266 KiB)
```

لا يعمل أي شيء قبل أن تجيب بـ **yes**. وكل ملف `.xvr` يُفحص قبل نسخه، والملف
التالف يُتخطّى مع ذكر السبب. بعد ذلك تعمل التطبيقات بأسمائها: اكتب `welcome`.

## بدون التحديث

أي فلاشة تعمل، سواء كان فيها `update.xvr` أو لا:

```
ls /media                          الفلاشة تظهر هنا كمجلد (وأجهزة USB أيضاً)
ls /media/APPS
run /media/APPS/game.xvc           تشغيل برنامج من الفلاشة مباشرة
/media/APPS/tool.xvr               ملف .xvr يعمل بمساره
install /media/APPS/game.xvc       نسخه إلى /dex: بعدها يعمل باسمه "game"
copy /dex/data/notes.txt /media/APPS/notes.txt     والنسخ إلى الفلاشة أيضاً
eject /media/APPS                  قبل نزع الفلاشة
```

الأوامر `copy -r` و`move` و`del -r` تعمل على الفلاشة كأي قرص، وتطبيق `fm`
يفعل كل هذا بالأسهم.

## التأكد من سلامة الملفات

الطقم يحمل ملف `SHA256SUMS`، فأمر واحد داخل itelx يخبرك هل الفلاشة فيها
بالضبط ما نُشر:

```
itelx:/> sum -c /media/APPS/SHA256SUMS
update.xvr: OK
dex/2048.xvr: OK
...
29 OK, 0 failed, 0 missing
```

ولأي ملف آخر قارن الـ SHA-256 الخاص به: على الكمبيوتر
`certutil -hashfile file SHA256` (ويندوز) أو `sha256sum file` (لينكس)، وعلى
itelx `sum file`.

## معلومات مفيدة

- الأسماء الطويلة والأسماء العربية للملفات تعمل (نظام FAT يحفظها بـ UTF-16).
- الأمر `usb` يعرض أجهزة USB وأسماءها في `/media`، والأمر `mounts` يعرض
  الأقراص المستخدمة.
- نزع الفلاشة بدون `eject` قد يضيّع ما كان يُكتب عليها.
- قسم EFI الخاص بقرص النظام يظهر في `/media` أيضاً، للقراءة فقط.
