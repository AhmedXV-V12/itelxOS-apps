# تعلّم صناعة التطبيقات لنظام itelxOS

[English](../en/README.md)

نظام itelxOS نظام تشغيل 64 بت له نواته الخاصة ونظام ملفاته الخاص (ITFS)
وطرفيّته الخاصة، وليس لينكس. يشغّل النظام نوعين من البرامج:

<div dir="rtl">

| | XVC | XVR |
|---|---|---|
| ما هو | لغة برمجة: البرنامج ملف نصي | ملف تنفيذي: كود آلة |
| امتداد الملف | `name.xvc` | `name.xvr` |
| يُكتب بـ | أي محرر نصوص (على الكمبيوتر أو داخل itelx) | `xvc2xvr` من برنامج XVC، أو مترجم C مع الـ SDK |
| من يشغّله | مفسّر XVC (`/system/xvc.xvr`) | النواة نفسها مباشرة |
| مناسب لـ | التطبيقات البسيطة: أدوات، ألعاب، قوائم، تعلّم | التطبيقات المعقدة: شاشة كاملة، سرعة، استدعاءات النظام |

</div>

هذه الصفحات تأخذك من الصفر حتى يعمل تطبيقك أنت على itelx:

<div dir="rtl">

1. [لغة XVC](1-xvc-language.md): كل ما في اللغة، مع أمثلة
2. [برنامجك الأول](2-first-program.md): اكتبه، شغّله، أصلح أخطاءه
3. [من XVC إلى XVR](3-xvc-to-xvr.md): حوّل برنامج XVC إلى ملف تنفيذي XVR، داخل itelx أو على الكمبيوتر
4. [تطبيقات XVR بلغة C](4-xvr-in-c.md): التطبيقات المعقدة بالـ SDK الموجود في هذا المستودع
5. [نقل البرامج إلى itelx بالفلاشة](5-usb-fat32.md): FAT32، وعرض التحديث، والتثبيت

</div>
